# Progressive web applications

Enable generated PWA files in `slamhaus.yaml`:

```yaml
pwa:
  enabled: true
```

Builds emit `manifest.webmanifest`, `service-worker.js`, and an external
registration module. The manifest uses the configured site name and base path.
The service worker is generated by Slamhaus; users do not write JavaScript.

Use the C++ SDK's install, online-state, storage, lifecycle, display, input,
touch, sensor, and reduced-motion helpers for application behavior. Permission
and user-gesture failures are returned as typed results where the browser API
requires them.
