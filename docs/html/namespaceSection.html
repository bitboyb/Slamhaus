auto Section::HandleBlockElements ( const std::string & line,

Parser::ParseState & pState,

Handles Slamhaus block elements like :section, :hero, and :column. Detects open/close lines and outputs corresponding HTML.

  • Buffers column content until :/column is encountered.
  • Applies section and hero attributes like id and alignment.
  • Works with Parser::ParseState and Parser::ColumnState.
Parameters
lineThe raw line from the Markdown file
htmlThe output HTML stream
pStateThe current parsing state
cStateThe column block state (for :column)
seoOptional SEO data (for parsing metadata within columns)
Returns
True if the line was handled by this module
