bool Script::HandleScript ( const std::string & line,
std::istringstream & iss,
std::ostringstream & html,
Parser::ParseState & pState )

Handles a single @script[...]() block and emits the corresponding <script> glue code. Parses attributes like src, call, args, and types, and generates JavaScript that binds to WebAssembly-compiled C++ functions using Emscripten's ccall interface.

Parameters
lineThe raw @script[...]() line.
issInput stream for the rest of the Markdown file (for future expansion).
htmlOutput stream for writing generated HTML/JS.
pStateCurrent parser state (used to close lists/paragraphs before insertion).
Returns
True if the script was parsed and inserted; false otherwise.
