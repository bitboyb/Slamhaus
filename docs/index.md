# Slamhaus API documentation

Slamhaus is a Markdown-first static-site compiler with a typed C++17 SDK for
WebAssembly pages.

This reference covers the public compiler interfaces under `src/` and the
browser-facing SDK in `sdk/slam/slam.hpp`. Start with:

- [Language API](namespaceLanguage.html)
- [Project API](namespaceProject.html)
- [Slam SDK](namespaceSlam.html)

For practical usage, consult the repository's C++ SDK guide and language
reference alongside this generated API reference.
