# About Slamhaus

Slamhaus keeps content in Markdown and browser behavior in typed game-oriented
code. Its compiler, project generator, language server, C++ SDK, managed
Emscripten integration, and examples ship from one repository.

The compiler is deterministic, validates routes before replacing output, and
generates accessible semantic HTML from its UI primitives.
